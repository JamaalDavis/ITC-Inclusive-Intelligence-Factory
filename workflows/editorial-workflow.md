# Editorial workflow

1. Validate task and authority.
2. Select minimal relevant context.
3. Gather evidence (future external integration).
4. Draft and design (future model integration).
5. Run deterministic checks and evaluation rubric.
6. Conduct human source and accessibility review.
7. Obtain explicit, auditable publishing approval.
8. Publish through a restricted adapter (future integration).
9. Record outcome metrics, feedback and version changes.

The v0.1 demo executes steps 1–2, simulates 3–4 via fixture, and executes a subset of step 5; it blocks at step 6. No real publishing is performed.
