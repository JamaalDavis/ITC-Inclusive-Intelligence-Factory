# Inclusive Context Engineering

## Method
1. Read only relevant task inputs and context.
2. Apply this skill's checks and record assumptions.
3. Deliver concrete outputs and cite evidence where applicable.
4. Flag uncertainties, inaccessible paths and required human review.

## Success condition
A reviewer can trace requirements, findings, and decisions without relying on an AI's unsupported confidence.
